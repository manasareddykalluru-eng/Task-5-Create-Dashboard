# Task-5-Create-Dashboard
Student Performance Analysis Dashboard created using Microsoft Power BI.

## Project Title
Student Performance Analysis Dashboard

## Objective
To create an interactive dashboard to visualize and understand students' academic performance.

## Tool Used
Microsoft Power BI Desktop

## Dashboard Features
- Total Students KPI Card
- Average Math Score
- Average Reading Score
- Average Writing Score
- Gender-wise Performance Analysis
- Parental Education-wise Performance Analysis
- Interactive Slicers

## Dataset
Students Performance Dataset

## Outcome
Successfully developed an interactive Power BI dashboard to analyze and visualize students' academic performance.
